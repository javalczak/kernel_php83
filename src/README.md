# Kod referencyjny

Ten katalog (`src/`), wraz z `templates/`, `config/module.php`, `config/features.php`
oraz `tools/reset-db.php`, to fragment wcześniejszego projektu "Fiestalettings"
pozostawiony **celowo** jako materiał referencyjny — nie jest to działająca aplikacja
i nie wszystkie odwołania (klasy, pliki konfiguracyjne, szablony) w tych plikach
faktycznie istnieją w repozytorium.

Nie traktuj tego jako gotowego do uruchomienia kodu ani jako części szkieletu
frameworka (`engine/`). Konwencje kodowania wyciągnięte z tych plików opisane są
w `.ai/style-guide.md` — to on jest źródłem prawdy o obowiązujących standardach,
nie ten katalog.

Nie usuwaj tych plików bez wyraźnej zgody autora projektu.
